# Drill #14 — 새떼 비행 애니메이션

LEC16(시간) 실습의 `main.py` 게임(소년이 달리고 공을 던지는 상태)에
`bird_animation.png`를 사용한 새 10마리를 추가해, 새떼가 화면 좌우를 반복해서 날도록 했습니다.
소년에 쓰인 **frame_time 기반 이동 / 애니메이션** 방식과 물리 단위를 그대로 새에 적용했습니다.

## 실행

```
python main.py
```

| 키 | 동작 |
|---|---|
| `←` `→` | 소년 이동 |
| `SPACE` | 소년이 공 발사 |
| `D` | 새마다 속도(km/h), 날갯짓 빈도(Hz), 현재 프레임 번호 표시 |
| `ESC` | 종료 |

## 1. 스프라이트 시트 분석

| 항목 | 값 | 근거 |
|---|---|---|
| 이미지 크기 | 918 x 506 | |
| 배치 | 5칸 x 3줄, 마지막 줄 4칸 → **14프레임** | |
| 프레임 폭 | **182 px** | 각 칸의 새 눈 중심이 정확히 182 px 간격 (918/5 = 183.6 으로 자르면 뒤 프레임일수록 새가 밀려 떨림) |
| 프레임 높이 | **169 px** | 506 / 3 ≈ 168.7 |
| 재생 순서 | 행 우선 (위 줄 → 아래 줄) | 1줄: 날개 위→앞으로 내리기, 2줄: 날개 아래, 3줄: 다시 올리기 → 1줄 첫 프레임으로 자연스럽게 연결 |

pico2d는 왼쪽 아래가 원점이므로 `bottom = 506 - (row + 1) * 506 / 3` (337, 168, 0) 으로 계산합니다.

## 2. 물리 단위

- `PIXEL_PER_METER = 10 / 0.3` (10 pixel = 30 cm, 소년 boy.py 와 동일) → 약 33.3 px/m
  → 소년, 공, 새가 모두 같은 세계 단위에서 움직임
- 새 한 프레임(날개 포함 옆모습)을 **1.5 m** 크기의 대형 새로 가정 → 화면 폭 50 px, 높이 46 px

## 3. 비행 속도

```
FLY_SPEED_KMPH = 30 ~ 40 (개체별 랜덤, 기준 35)
35 km/h = 35000 / 60 / 60 = 9.72 m/s = 9.72 * 33.3 ≈ 324 pixel/s
x += dir * speed_pps * frame_time
```

## 4. 날갯짓(애니메이션 프레임) 속도

소년 달리기의 "보폭 → 초당 프레임" 계산과 같은 논리입니다.

```
DISTANCE_PER_FLAP_M = 3.5                      # 날갯짓 1회 동안 나아가는 거리
FLAPS_PER_SECOND    = 9.72 / 3.5 ≈ 2.78 회/초   # 대형 새의 실제 날갯짓 2~3 Hz
FRAMES_PER_SECOND   = 2.78 * 14 ≈ 38.9 프레임/초
frame = (frame + frames_per_second * frame_time) % 14
```

이동 속도와 날갯짓 빈도가 같은 식에서 나오므로, 빠른 새는 날갯짓도 빠르고 느린 새는 느립니다.
`frame + 1` 방식과 달리 PC 성능(FPS)에 따라 날갯짓 속도가 바뀌지 않습니다.

## 5. 새떼 10마리

- 위치 x 100~1500, y 250~560 랜덤 (소년(y=90)과 잔디 위 하늘 영역)
- 속도 30~40 km/h 랜덤 → 날갯짓 약 2.4~3.2 Hz
- 시작 프레임 랜덤 → 10마리가 같은 박자로 날갯짓하지 않음
- 화면 끝(몸 절반 안쪽)에 닿으면 방향 전환, 왼쪽으로 날 때는 좌우 반전
